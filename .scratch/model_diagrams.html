Why 10 features, not 64: at ~30 real training rows per fold, a wide feature set overfits before it informs. The compact set was chosen by ablation (k ∈ {5,8,10,12,20}), not by picking the best-looking result after the fact — k=10 won on the same folds every other candidate used.

AFT Survival (Weibull / LogNormal)

TARGET · Y3_RECOVERY_DAYS

Right-censored accelerated-failure-time model. The 90-day cap is treated as "hasn't recovered yet," not as an observed value of 90 — a different likelihood for the same target, not a redefinition of it.

— real ranking signal, point prediction still not confirmed

Split verdict: C-index 0.568 (mean of 0.696 / 0.448 / 0.529 / 0.600 across folds) beats the 0.5 chance line — it ranks which events recover faster than which others better than a coin flip. RMSE still loses to a flat training-mean guess (29.47 days), and calibration is weak (predicted-vs-actual correlation ≈ −0.03): trust the ranking, not the day count.

Every model above shares one walk-forward split geometry (30-event train / 10-event test / 10-event step) and the same fold-boundary purge for Y1's 5-day label horizon. Full numbers: docs/METHODOLOGY_AUDIT.md, artifacts/results_regression.pkl.
